Penalty Rules

Rule 1 — Long runs

+3 for each row or column containing 5 consecutive modules of the same color, +1 for every additional same-color module. Penalizes horizontal/vertical streaks that confuse decoders trying to lock onto module boundaries.

Rule 2 — 2×2 blocks

+3 for every 2×2 block of the same color. Counts overlapping blocks. Penalizes large monochrome regions that break the expected noise pattern.

Rule 3 — False finders

+40 for each occurrence of the pattern 1:1:3:1:1 (dark-light-dark-dark-dark-light-dark) followed or preceded by 4 light modules. This mimics the real finder pattern and can confuse the decoder's initial lock.

Rule 4 — Dark balance

+10 × floor(|%dark − 50| / 5). Penalizes codes that drift far from 50% dark modules, which keeps contrast histograms symmetric across the matrix.
